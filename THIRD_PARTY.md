# Procedencia y licencias

Ares contiene código e instrucciones originales. Paperclip y Hermes se referencian como submódulos sin modificar, sujetos a sus respectivos archivos LICENSE. La imagen conserva el código y licencias upstream; las skills oficiales se copian completas con sus archivos de soporte.

Las librerías Python y sus versiones/transitivos están en uv.lock; mantienen sus licencias propias. LibreOffice se instala desde Debian, con sus avisos en el paquete del sistema. Las referencias metodológicas de docs/CANDIDATES.md no significan afiliación ni validación de Ares por sus autores.

No se incorporó código de PyMuPDF, FinanceToolkit, EdgarTools, Arelle, sec-edgar ni agency-agents. Las siete skills Ares son adaptaciones originales acotadas; se consultaron procedimientos financieros públicos para comparar criterios, sin trasladar herramientas privadas ni permisos externos.
